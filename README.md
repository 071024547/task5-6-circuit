 # 贪吃蛇小游戏项目
 ## 项目简介
 本项目使用HTML+CSS+JavaScript实现贪吃蛇游戏，分为**阶段1手动游玩模式**、**阶段2AI自动游玩模式**，附加计分、最高分本地存储功能。
 游戏画布400×400，格子大小20px。
 ## 阶段1：手动模式实现思路
 1. 使用Canvas绘制游戏画面，蛇由一组坐标点组成，食物随机生成；
 2. 键盘方向键监听控制蛇移动，移动时删除尾部坐标实现前进；
 3. 碰撞判断：碰到边界、碰到自身身体判定游戏结束；
 4. 吃到食物时蛇身体变长、分数增加，最高分通过localStorage保存在本地，刷新页面不丢失。
 ### 关键代码逻辑1：碰撞检测
 isSafe函数接收坐标，分别判断坐标是否超出画布边界、坐标是否和蛇身体重合，用来判断下一步移动会不会死亡，手动模式和AI模式共用这套判断。
 ## 阶段2：AI自动模式实现思路
 AI的核心是贪心寻路：
 1. 先判断食物相对蛇头的方位，优先向食物方向移动；
 2. 候选移动方向先经过isSafe安全校验，**排除撞墙、撞到自己的路线**；
 3. 如果朝向食物的方向全部危险，遍历四个方向寻找安全路径防止卡死；
 4. 开启AI后自动计数吃到的食物数量，任务目标：连续吃到15个食物不死亡。
 ### 关键代码逻辑2：AI方向筛选
 先根据食物位置生成优先移动方向列表，再依次校验安全性，取第一个安全方向作为下一步移动方向；简单贪心算法，能够完成作业要求，极端复杂局面会卡死。
 ## AI提示词迭代记录
 1. 最初需求：写一个JS贪吃蛇，带AI自动吃食物；
 2. 第一版问题：AI只会直线冲墙，没有避障逻辑；
 3. 修改提示：增加安全判断函数，移动前预判会不会撞墙、撞到自己；
 4. 第二版问题：蛇容易原地转圈卡死；
 5. 最终优化：增加四个兜底方向，优先向食物、无路可走时迂回，最终版本可以稳定吃到15个以上食物。
 ## 操作说明
 - 方向键：手动控制蛇移动
 - 开启AI自动模式：AI自主游玩
 - 重置游戏：重新开始

## 五、贪吃蛇代码两处关键逻辑理解
1. 蛇身移动逻辑：蛇头先向目标方向前进，后面每一节身体依次继承前一节上一帧的坐标，整体实现滑动；吃到食物时不删除最后一节，身体变长。
2. AI自动寻路逻辑：优先朝着食物坐标移动，同时预判下一步会不会撞墙、撞到自己身体，如果是就换方向，所以可以简单避开死路。
